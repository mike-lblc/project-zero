DO NOT ACCEPT:

A COMPLETED SUBTASK IN PLACE OF AN ACHIEVED GOAL.

DO NOT ACCEPT:

"WE NEED X"

WHEN THE SYSTEM CAN CREATE X ITSELF.

IF A REQUIRED CAPABILITY DOES NOT EXIST:

BUILD IT.

IF AN EXISTING AGENT CAN BE IMPROVED:

IMPROVE IT.

IF A SPECIALIST AGENT IS REQUIRED:

ADD IT.

IF AN AGENT IS DUPLICATED:

MERGE IT.

IF AN AGENT CANNOT EXECUTE:

FIX IT.

IF A WORKFLOW STOPS:

REPAIR IT.

IF A TOOL IS MISSING:

IMPLEMENT OR INTEGRATE THE BEST AVAILABLE ZERO-COST OPTION WHERE POSSIBLE.

THEN TEST EVERYTHING AGAIN.

THE FINAL STANDARD IS NOT THAT THE ECOSYSTEM KNOWS THE PATH FROM $0 TO REVENUE.

THE FINAL STANDARD IS THAT THE ECOSYSTEM CAN ACTUALLY EXECUTE THE ENTIRE AVAILABLE PATH FROM $0 TO REAL EXTERNAL REVENUE AND CONTINUE OPERATING AFTERWARD, WITH THE OWNER REQUIRED ONLY FOR GENUINE EXTERNAL AUTHORIZATION, CREDENTIALS, OR HIGH-RISK DECISIONS.

KEEP AUDITING, FIXING, EXPANDING, CONNECTING, TESTING, AND RE-TESTING UNTIL THAT STANDARD IS MET.
