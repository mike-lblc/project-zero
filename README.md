# P0

**[Данные рынка x402](https://mike-lblc.github.io/project-zero/)** ·
**[Бесплатный еженедельный отчёт](https://x402-bazaar-rank.x402-bazaar-rank-worker.workers.dev/join)** ·
**[MCP-сервер](https://x402-bazaar-rank.x402-bazaar-rank-worker.workers.dev/mcp)**

Полный обход рынка платных сервисов x402: 14 231 сервис с реальными метриками
использования за 30 дней. Сводка и образец бесплатны, полный датасет $1.25.

Автономная система агентов. Задача одна: **доказать, что агенты способны заработать
с нуля, не потратив ни цента.**

## Как устроено доказательство

Заявление сформулировано так, чтобы его можно было **опровергнуть**:

> Агенты, начав с $0 и потратив $0, получают проверяемую выручку.

- **Засчитано:** строка в таблице `payments` с настоящим хешем транзакции,
  при пустой таблице `spend`, от **постороннего** плательщика.
- **Провалено:** окно вышло, `spend` пуста и `payments` пуста. Тогда мы это признаём.

Платёж самому себе заполнил бы таблицу и **опроверг** тезис, поэтому запрещён.

Чтобы доказательство нельзя было подделать, ведётся журнал `human_interventions` —
каждое действие человека: создание аккаунтов, вставка ключей, одобрения. Итоговый
отчёт всегда показывает обе колонки: что сделали агенты и что сделал человек.

## Правила, которые исполняются кодом, а не обещаниями

| Правило | Где живёт |
|---|---|
| Локальная модель **не принимает решений** — только механика | `core/router.py` |
| Запрещённые действия (аккаунты, KYC, капча, траты) блокируются | `core/guard.py` |
| Предложение без **фальсификатора** отклоняется не читая | `agents/council.py` |
| Одно обоснованное возражение **блокирует** необратимое действие | `agents/council.py` |
| Утверждение без источника **не считается** | схема `evidence` → `sources` |

Голосование одинаковых моделей — фальшивая безопасность: они ошибаются
одинаково и потом соглашаются друг с другом. Поэтому защита здесь
**состязательная**, а не консенсусная: у Оппонента задача — убить предложение.

## Состав

    core/     db, шина агентов, роутер моделей, гейты
    agents/   совет, разведка, развитие, команда расширения, непрерывный цикл
    service/  платный x402-сервис + дашборд + страница подписки
    audit.py  74 проверки фактами, а не на слово

## Продукт

Ранжированный поиск по x402-сервисам: у нас полный краул рынка с метриками
реального использования, чего нет у официального индекса.

Тарифы: `/search` $0.01 · `/report` $0.10 · `/alpha` $0.50 · `/dataset` $1.25

## Запуск

    py -3.13 -X utf8 core/db.py          # создать базу
    cd service && npm install && node server.js
    py -3.13 -X utf8 agents/worker.py    # непрерывный цикл
    py -3.13 -X utf8 audit.py            # проверить, что всё правда

`.env` в репозиторий не попадает. Ключи туда вписываются руками.
