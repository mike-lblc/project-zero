Query it live

The same data is searchable as an MCP server, listed in the official registry as io.github.mike-lblc/x402-bazaar-rank. Basic search is free:

curl -X POST https://x402-bazaar-rank.x402-bazaar-rank-worker.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"search_x402_services","arguments":{"query":"web search"}}}'

Deeper endpoints — full market report, underserved-niche analysis, complete dataset — are payable over x402 on the same host, from $0.01.
