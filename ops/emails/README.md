# ГОТОВЫЕ ПИСЬМА ДЛЯ ВСТАВКИ В EMAILOCTOPUS

Что делать (один раз, ~5 минут):

1. EmailOctopus -> Automations -> Create automation
2. Триггер: Contact tagged -> тег `seq:1`
3. Действие: Send email -> вставить тему и текст из файла step1.txt
4. Повторить для seq:2 и seq:3 (на бесплатном тарифе 3 автоматизации)

Дальше агенты ставят теги сами по расписанию — отправка пойдёт без тебя.

| шаг | через сколько дней | тема |
|---|---|---|
| 1 | 0 | Данные, за которые агенты платят прямо сейчас |
| 2 | 2 | Где спрос выше конкуренции (по числу плательщиков) |
| 3 | 5 | Как принимать оплату от агентов без KYC |
| 4 | 9 | Что изменилось на рынке за неделю |
| 5 | 14 | Честно: сколько на этом реально зарабатывают |
